# Native local speech backend

This backend slice adds explicitly authorized, coordinator-local transcription to the optional pinned native listener. Native enrollment, `app.open`, dashboard and chore grants provide no audio authority. A controller must grant `speech.transcribe` to an active native client with `ellie speech grant CLIENT`; grants are stored separately in private `speech-authority.json` and can be listed or revoked explicitly.

Speech remains disabled unless the coordinator owner creates private mode-0600 `~/.ellie/native-speech.json` with exact JSON `{ "version": 1, "executable": "/absolute/path/to/whisper-cli", "model": "/absolute/path/to/model.bin" }`. The explicit availability request checks those configured local files. Ellie does not search for, download or select a model and has no cloud fallback.

`POST /native/v1/speech/transcriptions` accepts one 16 kHz mono PCM16 RIFF/WAVE body, at most 1,100,000 bytes and 30 seconds, with one canonical lowercase UUID in `X-Ellie-Turn-ID`. One turn per client and four globally may run. The complete JSON response is at most 16 KiB and contains only `{turnId,text}`, with text at most 2,000 UTF-16 units. Upload, inference and response loss never trigger an automatic retry. `GET /native/v1/speech/availability` runs only on explicit client request. `POST /native/v1/speech/transcriptions/{turnId}/cancel` with `{}` signals a matching owned active turn; disconnect, speech-grant revocation and native-session revocation also request cancellation. Cancellation cannot promise that already-running local computation stopped immediately.

Audio, transcripts, turn IDs, model paths and credentials are excluded from routine logs, JobStore and state JSON. The existing local Whisper adapter owns its random temporary directory, bounds input/output and deadlines, discards process output other than the final transcript, and removes its temporary turn data after completion or cancellation. This PR contains backend and synthetic HTTPS/process tests only. It does not request microphone permission, capture physical audio, add iPhone UI, contact an installed service or validate speech quality.
