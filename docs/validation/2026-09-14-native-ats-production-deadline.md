# Native ATS production deadline validation

PR #78 run `34873136826`, job `104073706244`, tested tree `547fd3dc1a98460e40dae7e1aaaf5fbffb39518e`. Its retained XCTest result reports `NativeEnrollmentATSTests.testProductionTransportConnectsToPinnedLocalHTTPSUnderATS` failed during session recovery with `timedOut`, surfaced as `unavailable`, after three seconds, before the initial session-recovery request reached its HTTP route. The suite passed 22 of 23 tests, including all six later speech tests against the same listener; the session/inventory/command/logout counters do not count speech traffic. The original result ZIP is retained locally with SHA-256 `d2fce2f2f77e90ed89bf306c50b0d6f2d8f9e222e3ce9e78430d93b51562d3d6`.

That first app-hosted recovery test supplied an artificial three-second transport timeout even though production recovery uses the ten-second default. The test now uses the production default. The existing desktop ephemeral pinned-HTTPS recovery test delays a valid response for four seconds and verifies that the default transport still succeeds with the required bearer and version headers. Its existing wrong-pin, wrong-hostname, certificate-date, slow-drip, and cancellation checks remain unchanged.

This corrects the test-to-production deadline mismatch. It does not identify the cause of the observed pre-request delay and does not add a retry or change production transport, TLS, pin, hostname, or deadline behavior.

The exact changed source passed the full repository check with 328 tests and one skip. On the physical MacBook using Xcode 16.2, SDK 18.2, and the iOS 18.3.1 Simulator runtime, the delayed desktop recovery passed once in 4.460 seconds and the app-hosted ATS suite passed once with exact session/inventory/command/logout/unexpected counts of `1/2/1/1/0`; its owned fixture and Simulator were removed. In a separate owned source copy, restoring the three-second override made the delayed desktop recovery fail with `unavailable` after 3.219 seconds. These tests used synthetic credentials and isolated temporary state; they did not access an installed app, household service, Keychain identity, or physical phone.

The correction was then combined with reviewed PRs #78, #80, and #77. That complete source passed the full local gate with 341 tests passed and one skipped. Separately, PR #80's preceding combined source passed its own CI run `34875317798`, including the original three-second ATS test; this is distinct evidence and does not explain the earlier delay. The corrected combined source still requires its own full CI before merge.
