# Native push-to-talk validation — 2026-09-13

All 59 native Swift tests passed. The final three-line process hardening was followed by another exact-source focused run: four voice tests passed, including cancellation with a 35-second operation deadline completing in under two seconds. Focused tests use recorder and transcriber actors plus isolated temporary executables. They cover explicit start, stop into local transcription, editable review, strict three-app parsing, cancellation, transcript clearing, rejection of a late result, refusal to start a second turn before noncooperative cleanup completes, bounded streaming output, termination of a process that ignores TERM, and a parent that exits while its descendant keeps stdout open. Existing native coordinator action tests continue to prove that only the explicit Open button dispatches and that cancellation remains outcome-unknown.

The app and test suite were built with full Xcode in an isolated temporary checkout. No microphone permission was requested, audio was captured, whisper model was executed, household coordinator was contacted or desktop command was sent. Physical microphone quality and AVAudioRecorder format behavior on different hardware remain acceptance work. Subsequent real-model and SwiftUI checks with synthetic audio are recorded separately in [the hardware validation record](2026-09-13-native-voice-hardware.md). Shared logs record test names and results only; they contain no audio, transcript, model path, command content, credential or household identity.

During development, an early fake recorder returned a synthetic file directly under the process temporary root. The store incorrectly attempted recursive cleanup of that returned file’s parent twice. A subsequent read-only inspection found the user temporary root, with mode 0700, and hundreds of unrelated entries still present, but it cannot prove that no child entry changed; the impact is unknown. Validation stopped immediately. The corrected interface gives every recording an opaque ownership token, and only the recorder can remove its exact recorded file followed by its recorded empty per-turn directory. Tests use their own uniquely created directories.
